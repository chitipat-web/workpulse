🔄 ตั้งค่า Real-time (Firebase)

ทำให้ กรอกเครื่องนึง อีกเครื่องเห็นทันที โดยต่อกับ Firebase ฟรีของ Google
  1. เข้า console.firebase.google.com สร้างโปรเจกต์
  2. เมนู Build → Realtime Database → Create Database → เลือก Start in test mode
  3. เมนู Project settings (⚙️) → General เลื่อนลงล่าง กด </> Web app สร้างแอป
  4. คัดลอกบล็อก firebaseConfig ทั้งก้อน มาวางช่องล่างนี้
  5. ตั้ง รหัสห้อง เป็นอะไรก็ได้ (ทุกเครื่องที่อยากเห็นยอดเดียวกันต้องใช้รหัสนี้)

🛡️ ยืนยันสลิปกับธนาคาร (กันสลิปปลอม)

ตรวจสลิปตัดต่อ/ปลอมโดยยืนยันกับธนาคารจริงผ่าน EasySlip
  1. สมัครที่ developer.easyslip.com (มีแพ็กเกจฟรีให้ลอง)
  2. คัดลอก API Key (Access Token) มาวางช่องล่างนี้ → กดบันทึก
  3. เวลาเพิ่มรายการ แนบสลิป ระบบจะเช็คกับธนาคารให้อัตโนมัติ

🆓 SlipOK (ฟรี 100 สลิป/เดือน)

ทางเลือกฟรีรายเดือน ผ่าน SlipOK — ต้องมี พร็อกซี Cloudflare คั่น (ฟรี ตั้งครั้งเดียว)
  1. สมัคร slipok.com → เอา API Key + Branch ID
  2. สร้าง Cloudflare Worker ฟรี วางโค้ดที่ผมเตรียมให้ (ใส่ Key + Branch ในนั้น)
  3. เอา URL ของ Worker มาวางช่องล่าง → บันทึก
ถ้าตั้งทั้ง EasySlip และ SlipOK ระบบจะใช้ SlipOK ก่อน (เพราะฟรี)
